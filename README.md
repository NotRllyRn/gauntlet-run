# Gauntlet Run

Play ten daily games in any order, with automatic scores, timers, screenshots, and shareable results. Pause and resume your run; results stay on your device.

## Chrome / Edge

1. [Download the Chrome ZIP](https://github.com/NotRllyRn/gauntlet-run/releases/latest/download/gauntlet-chrome.zip) and extract it to a folder you’ll keep.
2. Open `chrome://extensions` (Edge: `edge://extensions`) and turn on **Developer mode**.
3. Click **Load unpacked** and select the extracted folder containing `manifest.json`.
4. Pin **Gauntlet Run**, click its icon, and select **Start run**.

## Firefox

1. [Download the Firefox ZIP](https://github.com/NotRllyRn/gauntlet-run/releases/latest/download/gauntlet-firefox.zip) and extract it.
2. Open `about:debugging#/runtime/this-firefox`.
3. Click **Load Temporary Add-on** and select the extracted `manifest.json`.
4. Click **Gauntlet Run** in the extensions menu, then **Start run**.

**Firefox installation is temporary and ends when Firefox closes. Export runs before closing; temporary add-on data may be lost.** A permanent install needs a Mozilla-signed release, which is not included yet.

Chrome/Edge 120+ or Firefox 142+ required. Allow screenshot access when prompted.

## Updates

When **⬆ Update extension** appears, open it to download the latest release. For Chrome/Edge, replace the files in the same extracted folder and click **Reload** on the extensions page. For Firefox, export your runs first, then reload the temporary add-on from the new download.
